## 🌟 Vision

> *"Mental health is not a destination, but a journey — AuraWell is your companion along the way."*

AuraWell is a **premium, full-featured mental health platform** purpose-built for students. It unifies **professional therapy**, **peer support groups**, **AI-powered personality insights**, **mindfulness tools**, and **mood analytics** — all wrapped in a cinematic, Rolex-inspired UI that makes wellness feel luxurious, not clinical.

## 🚀 Getting Started

### Prerequisites

```
Node.js  ≥  18.0
npm      ≥  9.0
```

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/ippiliakhileshsai/FSAD-PRO_2-2.git
cd FSAD-PRO_2-2

# 2. Install dependencies
npm install

# 3. Set up environment variables
cp .env.example .env
# Edit .env with your API URL, Google OAuth Client ID, etc.

# 4. Start development server
npm run dev
```

The app will be available at **`http://localhost:5173`** ⚡

### Build for Production

```bash
# Create optimized production bundle
npm run build

# Preview production build locally
npm run preview
```

### Deploy

```bash
# Deploy to Vercel (recommended)
npx vercel --prod

# Or serve the dist/ folder with any static hosting
```

## ⚡ Performance Optimizations

- **Code Splitting** — Every page is `React.lazy()` loaded, reducing initial bundle
- **Route-level Suspense** — Spinner fallback while chunks load
- **Image Lazy Loading** — All images use `loading="lazy"`
- **Scroll Event Throttling** — `{ passive: true }` on scroll listeners
- **Zustand** — Minimal re-renders (selector-based subscriptions)
- **React Query** — 5-minute stale time, deduped requests
- **CSS Custom Properties** — Runtime theme changes without re-compilation
- **Production Build** — ~390KB JS (125KB gzipped), ~54KB CSS (9.5KB gzipped)

## 📂 Key Implementation Details

<details>
<summary><strong>🔌 JWT Token Management</strong></summary>
<br>

- Axios request interceptor auto-attaches `Bearer` token from Zustand store
- Response interceptor catches `401` → attempts silent refresh with `refreshToken`
- Failed refresh → automatic logout + redirect to landing page
- Token persisted via Zustand `persist` middleware to `localStorage`

</details>

<details>
<summary><strong>💬 WebSocket Chat Architecture</strong></summary>
<br>

- Native `WebSocket` API (no Socket.IO dependency)
- Connection lifecycle managed in `chatStore.js` (Zustand)
- Messages are JSON-serialized with `content` field
- `useWebSocket` hook handles connect/disconnect/send
- Auto-cleanup on component unmount via `useEffect`

</details>

<details>
<summary><strong>🎨 Scroll Animation System</strong></summary>
<br>

- `useIntersection` hook wraps `IntersectionObserver`
- Elements start with `opacity: 0; transform: translateY(40px)`
- On intersection (threshold 0.1), class `.visible` triggers CSS transition
- Observer disconnects after first trigger (performance optimization)
- Stagger classes: `.stagger-1` through `.stagger-6` (100ms increments)

</details>

<details>
<summary><strong>🧘 Breathing Exercise Engine</strong></summary>
<br>

- 4-phase cycle: Inhale (4s) → Hold (4s) → Exhale (6s) → Hold (2s)
- Circle scale animates via React state → inline `transform: scale()`
- Phase counter, cycle counter, and color transitions
- Start/Stop toggle with clean state reset

</details>
